# Third-party skills in this folder

Copied from the repositories below. Every copy keeps the upstream `LICENSE` (all MIT), and a public repo must keep those notices. Rules:

- Do not edit a copied skill in place. To update, re-copy the folder from upstream at a new commit, read its `SKILL.md` again and change the commit column here.
- A skill is instructions the agent follows, so read a new upstream version before copying it. At the commits below none of them run installers, phone home or touch files outside the project without asking; the scripts that upload (`blender-to-roblox/scripts/upload-asset.sh`) or install (`roblox-doctor --fix`) ask first and read keys only from environment variables.
- Skills are Markdown plus optional scripts, so they work in Claude Code on a PC and in cloud threads. Scripts that need Blender, Studio, Lune or `uvx` only run on a PC.
- Each skill's description sits in every agent's context. Add more only when a role needs them; prefer copying one folder over a whole pack.
