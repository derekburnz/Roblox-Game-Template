# Design docs

The one-page design goes in `docs/design/<game-slug>/gdd.md`, written with the `gdd-onepager` skill. Tuning numbers go in `docs/design/<game-slug>/tuning.md`, and each feature that needs more than a paragraph gets `docs/design/<game-slug>/features/<feature>.md` in the same template.

If the game started with the Planning agent, copy its agreed one-page design here as the first commit of the design folder.
